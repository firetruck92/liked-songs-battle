# Liked Songs Battle

Турнир из твоих лайкнутых треков в Spotify: из каждой пары оставляешь один трек, пока не останется самый любимый.

**Сайт:** https://firetruck92.github.io/liked-songs-battle/

## Возможности

- Лайки загружаются через [Exportify](https://exportify.app): кнопка на сайте открывает его в окошке рядом, там входишь через Spotify и жмёшь Export у Liked Songs, а скачанный `liked.csv` бросаешь в любое место страницы. Можно сразу несколько CSV, `YourLibrary.json` из экспорта данных Spotify или просто список строками.
- Обложки альбомов и короткие отрывки треков через встроенный плеер Spotify.
- В турнир можно взять все треки, последние лайкнутые или случайную выборку. Если число треков не степень двойки, сначала идёт отборочный раунд.
- Отмена хода. Сайт ничего не запоминает: после перезагрузки всё начинается с чистого листа.
- В конце — итоговая таблица и кнопка «Поделиться»: картинка с результатом (PNG 1080×1350: победитель и топ-8, адрес сайта) + ссылка на сайт. На телефоне — системное меню «Поделиться», на компьютере картинка и ссылка копируются в буфер. Плюс кнопки X, Telegram, WhatsApp, Instagram, VK, Facebook, Reddit.
- Интерфейс на 10 языках: русский, английский, украинский, немецкий, французский, испанский, португальский, китайский, арабский и иврит (для арабского и иврита — вёрстка справа налево). Язык берётся из настроек браузера, переключатель с флагами — в шапке.
- Управление с клавиатуры: `←` / `→` — выбрать, `↓` — случайно, `Z` — отменить.

Всё работает в браузере: файлы никуда не отправляются и нигде не сохраняются.

## Локальный запуск

```
python -m http.server 8000 --bind 127.0.0.1
```

и открой http://127.0.0.1:8000/

## Структура

- `src/template.html` — разметка, стили и интерфейс
- `src/core.js` — логика турнира
- `src/i18n.js` — тексты интерфейса на всех языках и переключатель языков
- `build.py` — собирает `index.html` (сайт) и `dist/claude-artifact.html` (версия для Claude-артефакта без обложек и плеера)

После правок в `src/` запусти `python build.py`.

## Деплой

Сайт собирается и публикуется через GitHub Actions (`.github/workflows/pages.yml`) при каждом пуше в `main`: workflow запускает `build.py` и выкладывает `index.html` на GitHub Pages. Один раз нужно включить в **Settings → Pages → Source: GitHub Actions**.
